# Changelog

Ce projet suit le format Keep a Changelog et le versionnage semantique avant la
stabilisation de l'API publique.

## [0.1.0-beta.1] - 2026-08-26

### Ajoute

- Radar local, demo synthetique et stockage SQLite.
- Pipeline deterministe de normalisation, deduplication, faits et scoring explicable.
- API FastAPI locale, CLI et interface React.
- Configuration YAML versionnee et politique `manual_only` pour LinkedIn,
  Indeed et Welcome to the Jungle.
- Documentation publique, audits et workflows de release reproductible.

### Limites connues

- Aucun connecteur distant n'est active dans la configuration exemple.
- Aucune fonctionnalite de candidature ou d'auto-candidature n'est incluse.
