# Support

Le support est assure en best effort pour la derniere release publiee.

## Choisir le bon canal

- Utilise une Issue de bug pour un comportement reproductible de la derniere
  release, avec les versions, les etapes et des donnees fictives.
- Utilise une Issue de fonctionnalite pour une proposition dans le perimetre
  local et explicable.
- Utilise un GitHub Security Advisory prive pour une vulnerabilite.
- Consulte [la configuration](docs/CONFIGURATION.md) pour l'installation et
  [la politique des sources](docs/SOURCES_POLICY.md) avant une question de collecte.

Les Issues ne sont pas un canal de support pour CV, candidatures, cookies,
jetons, cles API, mots de passe ou donnees personnelles. Aucune promesse de
delai, de compatibilite historique ou d'integration de source n'est faite.
